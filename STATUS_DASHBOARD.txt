╭─────────────────────────────────────────────────────────────────────────╮
│ 📞 TROUBLESHOOTING                                                      │
╰─────────────────────────────────────────────────────────────────────────╯

  ISSUE: CLI doesn't run
  SOLUTION: chmod +x redzone_recon && ./redzone_recon github.com

  ISSUE: Module not found
  SOLUTION: source .venv/bin/activate && pip install -r requirements.txt

  ISSUE: Server won't start
  SOLUTION: lsof -i :8000 (check if port in use)
           Use different port: python3 redzone_server.py 9000

  ISSUE: No results from scan
  SOLUTION: Normal if Amass/Sn1per not installed (optional)
           WHOIS and DNS still work. Install tools for better coverage.

  ISSUE: Graph not rendering
  SOLUTION: Clear browser cache (Cmd+Shift+R)
           Try different browser

  See SYSTEM_TEST_REPORT.md for more troubleshooting
